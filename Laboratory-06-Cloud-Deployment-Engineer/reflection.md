# Mission Reflection

Writing a docker-compose.yml file made my work feel lighter and more fun. Instead of typing many long commands one by one, I only needed one file to tell Docker what to do. This is called Infrastructure as Code, and it saves time while making sure everything runs the same way every time. I learned that YAML is very strict. If I make a small mistake, like using a Tab instead of spaces, the file will not work. At first this was frustrating, but it taught me to be careful and patient. Paying attention to details is important for cloud engineers. We also used environment variables like MYSQL_PASSWORD. These are like secret notes that containers can read. They keep the setup safe and make it easy to change later without rewriting the whole file. When I saw Nextcloud running in just a few minutes, I felt proud and amazed. With only a few lines of YAML, I had a working private cloud system. It made me realize how powerful containers are and gave me confidence that I can do real deployments. Since Mission 1, I grew from learning simple commands to building multi‑tier architectures. This journey made me excited to keep learning more about cloud computing.
