# Client Recommendations

## Client A - Startup Company
**Recommended Platform:** Google Cloud Platform (GCP) 
This startup is launching a new mobile application with a limited budget but expects rapid growth in the coming years. They need a cost-effective and scalable cloud solution.  
 
**Useful Services:**  
- **Firebase** – Mobile backend for authentication, database, and hosting  
- **Cloud Run** – Serverless compute for scalable apps  
- **BigQuery** – Analytics for user and app data  

---

## Client B - University
**Recommended Platform:** Microsoft Azure  
The university already uses Windows Server, Microsoft 365, and Active Directory. They want to migrate some services to the cloud while maintaining compatibility with their existing Microsoft environment.  

**Useful Services:**  
- **Azure Virtual Machines** – Hosting academic applications  
- **Azure Active Directory** – Identity and access management  
- **Azure SQL Database** – Cloud-based relational database  

---

## Client C - AI Research Company
**Recommended Platform:** Google Cloud Platform (GCP) 
This company develops Artificial Intelligence and Machine Learning applications that require high-performance computing and advanced AI frameworks.  
  
**Useful Services:**  
- **Vertex AI** – End-to-end ML model development and deployment  
- **Tensor Processing Units (TPUs)** – Specialized hardware for AI workloads  
- **Google Kubernetes Engine (GKE)** – Scalable container orchestration  

---

## Client D - Global E-Commerce Company
**Recommended Platform:** Amazon Web Services (AWS)  
A multinational online shopping company serves customers worldwide. They require highly available infrastructure with automatic scaling to handle fluctuating traffic.  

**Useful Services:**  
- **EC2** – Compute instances for web servers  
- **RDS** – Managed relational database for transactions  
- **CloudFront** – Content delivery network for global customers  
- **Auto Scaling** – Automatic scaling of resources based on demand  

## Multi-Cloud Decision Matrix

| Business Requirement   | Recommended Platform | Justification |
|------------------------|----------------------|---------------|
| Startup Company        | GCP                  | Cost-effective, developer-friendly, scalable with Firebase and Cloud Run |
| Enterprise Organization| AWS                  | Broadest range of services, mature ecosystem, reliable for large-scale workloads |
| Microsoft Environment  | Azure                | Seamless integration with Windows Server, Active Directory, and Microsoft 365 |
| AI / Machine Learning  | GCP                  | Strongest AI/ML tools (Vertex AI, TPUs) and Kubernetes leadership |
| Kubernetes Deployment  | GCP                  | GKE is industry-leading, simple to manage and scale |
| Global Web Application | AWS                  | Largest global infrastructure, CDN (CloudFront), Auto Scaling for high availability |
