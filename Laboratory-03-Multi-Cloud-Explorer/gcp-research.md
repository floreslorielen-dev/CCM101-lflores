# Google Cloud Platform (GCP)

## Brief Overview
Google Cloud Platform (GCP), launched in 2008, is known for innovation in AI, data analytics, and Kubernetes.

## Global Infrastructure
- 40+ Regions
- Availability Zones
- Global fiber network

## Cloud Management Console
Google Cloud Console provides a simple, developer-friendly interface for managing services.

## Four Core Services
1. **Compute Engine** – Virtual machines
2. **Cloud Storage** – Object storage
3. **VPC** – Networking
4. **Cloud IAM** – Identity and access management

## Three Advantages
- Strongest in AI/ML (TensorFlow, Vertex AI)
- Industry-leading Kubernetes (GKE)
- Cost-effective for startups

## Typical Enterprise Use Cases
- AI/ML research companies
- Startups building scalable apps
- Data analytics and big data projects
