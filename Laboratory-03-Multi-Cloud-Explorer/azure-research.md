# Microsoft Azure

## Brief Overview
Microsoft Azure, launched in 2010, is a leading cloud platform known for seamless integration with Microsoft products.

## Global Infrastructure
- 60+ Regions worldwide
- Availability Zones for redundancy
- Hybrid cloud support

## Cloud Management Console
Azure Portal provides a unified dashboard to manage resources, subscriptions, and services.

## Four Core Services
1. **Virtual Machines** – Compute service
2. **Blob Storage** – Object storage
3. **Virtual Network** – Networking
4. **Azure Active Directory (AD)** – Identity management

## Three Advantages
- Best integration with Microsoft technologies
- Strong hybrid cloud capabilities
- Enterprise-grade security

## Typical Enterprise Use Cases
- Universities and organizations using Windows Server, Microsoft 365
- Hybrid cloud deployments
- Enterprise applications
