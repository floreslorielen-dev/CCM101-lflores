# Automation Research

## Bash Script
A Bash script is a text file that contains a series of Linux commands which can be executed automatically. The line `#!/bin/bash` at the top (called a shebang) tells the system to use the Bash interpreter to run the commands inside the file.

## Variables
Variables are used to store values such as folder paths or filenames. They make scripts flexible and easier to maintain because you can change the value in one place instead of editing multiple lines of code.

## Cron Job
A cron job is a scheduled task in Linux that runs automatically at specified times. It is essential in cloud operations because it removes human error and ensures that repetitive tasks like backups or monitoring run consistently without manual intervention.
