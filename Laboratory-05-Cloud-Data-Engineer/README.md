# Laboratory 05 - Cloud Data Engineer

## Mission Overview
In this mission, I deployed an S3-compatible object storage server (MinIO) using Docker. The goal was to simulate a real-world cloud storage environment for a client’s photo-sharing application.

## Objectives
- Differentiate between Block, File, and Object Storage.
- Deploy MinIO using Docker with environment variables.
- Access the MinIO web console via port forwarding.
- Create a bucket and upload sample files.
- Document all steps using Markdown.
- Strengthen my GitHub Cloud Computing Portfolio.

## Tools Used
- Docker
- MinIO (quay.io/minio/minio)
- KillerCoda Playground (Ubuntu)
- GitHub
- Web Browser

## Skills Learned
- Practical deployment of containerized cloud services.
- Secure configuration using environment variables.
- Managing object storage buckets and uploads.
- Markdown documentation for technical workflows.
- Improved confidence with Linux and Docker commands.
