# Security Audit Report – Laboratory 08: Cloud Security Engineer

## Principle of Least Privilege (PoLP)
The Principle of Least Privilege means giving users and applications so that only the minimum access they need to perform their tasks. This also will reduces the risk of accidental misuse or malicious exploitation because no one has more permissions than necessary.

## Attack Surface
The attack surface of a virtual machine refers to all the possible entry points that attackers could exploit, such as open ports, services, or weak configurations. The larger the attack surface, the more opportunities hackers have to break in.

## Default Deny Policy
A Default Deny Policy blocks all traffic by default and by only allows specific trusted connections. This is also safer because instead of trying to block every possible hacker we only open the exact ports and services that are required.
