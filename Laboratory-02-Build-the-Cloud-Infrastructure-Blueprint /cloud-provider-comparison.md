## Guide Questions

### 1. Which cloud provider offers the broadest range of services? Explain your answer.
Amazon Web Services (AWS) offers the broadest range of services, having launched earlier than its main competitors and built out the largest service catalog spanning compute, storage, databases, analytics, machine learning, and IoT. Its head start allowed it to build the most mature ecosystem with extensive feature depth across nearly every technical domain.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?
Microsoft Azure is the recommended platform for organizations deeply integrated into the Microsoft ecosystem. It offers seamless, native integration with Active Directory (Microsoft Entra ID), Windows Server, Office 365, and SQL Server, often providing cost advantages through existing license agreements like Azure Hybrid Benefit.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?
Google Cloud Platform (GCP) is widely recognized for AI, Machine Learning, and Kubernetes services, as Google originally created Kubernetes and built GCP around high-performance data analytics and ML frameworks like Vertex AI and TensorFlow.

### 4. What similarities did you observe among the three cloud providers?
All three providers share core architectural patterns by offering foundational compute, storage, networking, and identity primitives mapped to pay-as-you-go, elastic billing models. They also enforce a shared responsibility model for security, support high availability across global regions and availability zones, and supply managed Kubernetes and serverless frameworks.
